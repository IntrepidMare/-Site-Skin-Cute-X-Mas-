### HOW TO APPLY A SITE SKIN ON Ao3

1.  Click the chapter index button at the top and select the version you want. You can choose between desktop and mobile version, and between light and dark mode.
    
2.  Go to the corresponding chapter and copy the CSS code.
    
3.  Go to your dashboard.
    
4.  Select "Skins" from the menu.
    
5.  Select the "Create Site Skin" button towards the top right of the page on desktop (or below the My Site Skins heading on mobile).
    
6.  Pick a name that is unique among all users, so be sure to include your username or another distinctive element (e.g. “Cute X-mas skin \[your username\]”).
    
7.  **IMPORTANT:** Set the skin type. Make sure it's set to **Site Skin**, not work skin. They're stored in the same place but work in different ways.
    
8.  Paste the CSS code you copied into the text area.
    
9.  Click "Submit".
    
10.  Once you get the confirmation that your skin was successfully created, scroll down to the bottom of the page and click on the "Use" button. Voilà! Now you have a new awesome skin!

*   Custom fonts (where available—usually desktop only).

*   Custom layout.
    
*   New layout for the blurb tags and star separator.
    
*   Fandoms box extended.
    
*   Banner image.
    
*   Wider single line breaks (no more massive wall of text without breaks in other people's fics!!).
    
*   First line indent across the site.
    
### USING FEATURED FONTS

Keep in mind that a font has to be installed on your operating system to work with the skin, so be sure to install on your computer/device the following (Downloadable from Google Fonts or similar sites):

*   Konde
    
*   Nunito

_Note: As it says above, custom fonts usually don't work on mobile._

### HOW TO CHANGE TO DIFFERENT FONTS

Go to the line code where it says /\*  Font Family  \*/ and change the fonts to the ones of your liking.
